# Calc
Simple WPF calculator with keyboard input.

## How to use?
Just input math problem from keyboard or buttons.

## Requirements

- **.NET Runtime:** 
  - For `calc-self-contained.exe` — **not required**, everything is bundled
  - For `calc-framework-dependent.exe` — **.NET 8.0 Runtime** ([download](https://dotnet.microsoft.com/download/dotnet/8.0))

### Dependencies

- [AngouriMath](https://github.com/asc-community/AngouriMath) — symbolic math engine
